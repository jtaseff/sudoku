Solve sudokus with python.

Attempts to follow solving logic that humans use, not just solving algorithms known such as bruteforce backtracking.
- finding last digit in a region
- finding a naked single, i.e. the only option for that cell
- finding a hidden single, i.e. only 1 spot a number can go in a region

Heavily influenced by the logic presented by the amazing sudoku.coach website. I have learned so much advanced technique from the campaign, and it is also the best solving interface I have found anywhere, and it's free?!
